# Проверка работоспособности и безопасности — 09.11.2026

Исходная версия: `675d91c8641a0aabbf2622453f7546020aa3407a` (`main`).
Проверены CLI, чтение локального дерева и GitHub, обработка зависимостей,
внешние списки и advisories, AST, экспорт, тесты и CI. Проверяемые сторонние
проекты читались только как данные; их код не исполнялся.

## Исправления

1. GitHub API и внешние списки: запрещены перенаправления; ответ API ограничен
   16 МБ и проверяется на ожидаемый тип. Ранее эти ограничения были неполными.
2. Локальное чтение: только обычные файлы, ограниченное чтение, проверка
   дескриптора после открытия, обход POSIX через дескрипторы каталогов.
   Ошибки обхода не скрываются. Добавлены суммарные лимиты файлов и байт.
3. Неполное чтение теперь возвращает код 2 и `scan.complete=false`;
   покрытие зависимостей не объявляется полным. Предупреждения сохраняются
   в текстовом отчёте и SARIF.
4. Вывод записывается атомарно. Запрещены конечные символические ссылки
   и перезапись существующих файлов внутри сканируемого исходного дерева.
5. Некорректные структуры манифестов дают неполный результат и диагностику;
   некорректные URL в исходном коде не обрушивают анализ. Превышение глубины
   анализа возвращает управляемую ошибку вместо traceback.
6. Диапазоны и теги версий отделены от точных версий: lock-режим сообщает
   неполноту, registry-режим разрешает диапазон перед advisory-запросом.
   Исправлены обновление ключей инвентаря и обогащение одинаковых пакетов
   из разных манифестов. Неподдерживаемые манифесты учитываются в полноте.
7. Сохранён регистр имён Go-модулей в идентификации и внешних совпадениях.
   Python taint-анализ работает и с расширением `.PY`.
8. AST-сканирование использует только заранее загруженные грамматики;
   скрытая загрузка грамматик при анализе исключена.
9. CI actions закреплены на SHA; проверки контрольных репозиториев
   запускаются для main и pull requests. Установщик Gitleaks работает
   в контейнерах без возможности восстановить владельца из tar-архива.
10. Актуализированы руководство, changelog и сведения о поддерживаемой версии.

- OSV проверка установленных версий tree-sitter-language-pack 1.22.1,

## Границы вывода

Проект работоспособен как статический инструмент первичного анализа.
Результат не доказывает отсутствие вредоносности: эвристики, поддерживаемые
форматы, исключения путей и доступность внешних баз ограничивают покрытие.
Реестровое разрешение незакреплённых версий остаётся приблизительным.
Проверка Windows/macOS и всех возможных версий Python локально не выполнялась.
Для изменяемого недоверенного дерева нужен стабильный снимок и изоляция;
POSIX-защита дескрипторов не переносится полностью на Windows.
Отчёты могут содержать фрагменты исходников и должны храниться соответственно.
Отсутствие записей в OSV и Gitleaks не является доказательством отсутствия
неизвестных уязвимостей или всех разновидностей секретов.
