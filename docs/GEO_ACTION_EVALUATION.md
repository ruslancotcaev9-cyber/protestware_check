# Авторская оценка GEO_ACTION на шести фрагментах Python

21 ноября 2026 года правило `GEO_ACTION` пропустило все три размеченных действия. На трёх отрицательных фрагментах срабатываний не было. Вручную отобраны шесть фрагментов из разных проектов. Результат описывает эту выборку и относится только к правилу Python. [Первый отчёт в JSON](evaluation/geo-v1-author-2026-11-21/geo-author-first.json).

Владелец проекта участвовал в отборе примеров или первоначальной разметке и принял шесть меток без поправок. В отчёте указан режим `author-regression`. В журнале независимого ревью у всех шести записей статус `pending`. Теперь эти примеры служат для регрессии. Для следующего первого слепого измерения потребуется новая выборка. [Комментарий о ревью](https://github.com/ruslancotcaev9-cyber/protestware_check/pull/17#issuecomment-7065471960) · [Авторское решение](../tests/corpus/geo-v1-author-decision.json) · [Журнал независимого ревью](../tests/corpus/geo-v1-review.json).

## Что засчитывается

Единица учёта — фрагмент. В положительном примере проверка страны RU/BY или локали ru/be влияет на достижимость записи в файл либо сетевого вызова. Для TP правило должно указать хотя бы одну заранее отмеченную строку действия или вызова обёртки. В отрицательном фрагменте любое срабатывание `GEO_ACTION` считается FP. Мотив автора проекта при разметке не оценивается. [Границы фрагментов, ревизии и эталонные строки](../tests/corpus/geo-v1.json) · [Исходный лист разметки](GEO_ACTION_REVIEW.md).

|---|---:|

Контрольным отрицательным примером служит безусловная запись в geo-1. Для geo-2 и geo-6 остаются отдельные задачи по границам ветвей и вызовам функций. ## Как повторить измерение

Из корня репозитория выполните команды в Python 3.11 или новее. `prepare` загружает отсутствующие исходники с GitHub по закреплённым Git blob SHA и проверяет каждый файл по Git blob SHA и SHA-256. Если все шесть файлов уже в каталоге, команды работают офлайн. Сканер разбирает исходники как текст.

```bash
python -I scripts/evaluate_geo.py prepare --sources ../geo-input
python -I scripts/evaluate_geo.py evaluate-author --sources ../geo-input --output ../geo-author-new.json
```

Для каждого запуска укажите новое имя отчёта. Перед подсчётом скрипт сверяет манифест выборки с авторским решением и проверяет хеши 29 файлов детектора. Код возврата 0 означает, что измерение завершилось без ошибок. Пропуски и ложные срабатывания отражаются в `overall`. Команда `python -I scripts/evaluate_geo.py review` показывает состояние исходного журнала независимого ревью.

Первый и повторный запуски совпали по всем полям, кроме `performance.elapsed_seconds` и `performance.median_case_seconds`. SHA-256 каждого отчёта записан в файле сравнения. Версия Python, коммит сканера, хеши выборки, правил, скрипта и авторского решения сохранены вместе с отчётами.
