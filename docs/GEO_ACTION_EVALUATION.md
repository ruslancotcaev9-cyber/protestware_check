# Внешняя оценка GEO_ACTION

Шесть фрагментов из шести внешних Python-проектов отобраны вручную по назначению и исходному коду. В выборке есть обусловленное регионом сетевое обращение, запись с ранним выходом, обычная локализация и запись независимо от выбора языка. В исследуемом правиле учитывается и локаль. Наличие связи не устанавливает мотив разработчика. Этот набор измеряет правило Python GEO_ACTION. Правило AST_GEO_ACTION для других языков имеет отдельную область.

[Лист для эксперта](GEO_ACTION_REVIEW.md) · [Координаты, границы фрагментов и кандидатные метки](../tests/corpus/geo-v1.json) · [Журнал ревью](../tests/corpus/geo-v1-review.json).

20 ноября 2026 года автор запроса сообщил в рабочем чате проекта, что проверил все шесть примеров и правок к ним нет. Сообщение относится к манифесту `838dc4e7e141efe89ba03cea24004ca74687b31041120a9f74ed7235f70f56af`.

На момент записи отсутствует связанное с учётной записью свидетельство независимости проверяющего. В журнале шесть записей `pending`. Для закрытия ревью подойдёт ссылка на комментарий или коммит проверяющего с указанием, участвовал ли он в исходном отборе и разметке. Первое измерение ожидает подтверждения независимости.

Состав выборки, исходные строки, Git blob SHA, SHA-256 и хеш набора файлов сканера зафиксированы перед первым измерением. Исходники хранятся у авторов. Загрузка в отдельный каталог проверяет обе контрольные суммы. Сканер анализирует фрагменты как текст. Установка зависимостей исследуемых проектов и запуск их кода не требуются.

```bash
python scripts/evaluate_geo.py prepare --sources /tmp/geo-input
python scripts/evaluate_geo.py review
python scripts/evaluate_geo.py evaluate --sources /tmp/geo-input --output geo-first.json
```

Первый вызов требует связи с GitHub. Два следующих работают офлайн. Первое измерение выполняется после независимой проверки всех шести меток. Состояния pending и disputed дают код 2 до обращения к детектору. Подтверждение в журнале привязано к байтам примеров; доверенное ревью удостоверяет автора решения. При изменении выборки или доказательных строк нужна новая версия манифеста и разметки.

Положительный пример засчитывается, если правило указало одну из заранее отмеченных строк вызова или действия. Для отрицательного достаточно любого срабатывания в выбранном фрагменте, чтобы зафиксировать FP. В JSON отдельно публикуются TP, FP, TN, FN, ошибки анализа и все строки срабатываний в координатах оригинала. Лишние срабатывания внутри положительного примера видны в outside_reviewed_evidence. Код возврата учитывает ошибки оценки. Малая целевая выборка не оценивает частоту ошибок в произвольных проектах.
