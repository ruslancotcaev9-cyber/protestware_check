Пять partial в регрессиях — проектные сценарии rimraf. Все четыре положительных
основных файла обнаруживаются, но анализ каждого остаётся частичным: для native
диагностирован spread объекта, для posix — рекурсия, для windows/move-remove —
рекурсия и spread. Ещё один отрицательный сценарий `opt-arg.ts` имеет spread.
Сохранённые находки не превращают эти проходы в полный анализ. В режиме required
такие случаи возвращают 2; регрессии заранее объявлены в auto.

Два оставшихся FN: `fs-extra-whole-v4-1` и `fs-extra-whole-v4-4`, связанные с
`graceful-fs` и локальной обёрткой над сторонним API. Bare package не признаётся
нативным API только по имени. Восемь partial внешней выборки сохранены отдельно
в JSON; текстовый fallback не является доказательством импортной идентичности.

## Что проверено для межфайлового анализа

Тесты покрывают ESM/CommonJS, статические переэкспорты, уникальный выбор пути,
прямые обёртки, явно вызываемые callback-параметры, значения по умолчанию и трассы
JSON/SARIF. Отдельно проверены затенение и переприсваивания, разрыв CommonJS alias,
подмена/удаление свойств, spread и повторные свойства, type-only imports,
неиспользуемые вложенные функции, некоторые литеральные мёртвые ветви.
Проверены выход за корень, неоднозначные и отсутствующие файлы, кодированные пути,
циклы, бюджеты, partial/required/off, повторное использование дерева, отсутствие
дополнительных чтений модулей и исполнения target-кода.

## Сопоставимость и ограничения

Восемь файлов rimraf, использованных для исправлений, исключены из внешней оценки
и перенесены в регрессию с исходными локальными модулями. Оценивается только
основной файл, находка в helper не засчитывается за него. Это проектный вход;
его результат нельзя сравнивать как независимое улучшение с прежним однофайловым
входом. Windows обнаруживается через синхронный fallback; фабрики функций,
возвращаемые функции и Promise callback dispatch в общем случае не разрешаются.

Все 64 внешних примера сохранены из v4, новых источников нет. Их результаты
повторяют те же 64 примера исторического прогона: TP=30/TN=32/FP=0/FN=2.
Независимой новой оценки качества здесь нет. Все метки предложены ассистентом;
человеческое ревью не выполнено. Журнал содержит 64 pending-записи,
`identity_verified=false`. Выборка целевая, небольшая и коррелированная;
нулевой FP в ней не гарантирует отсутствие ложных срабатываний на других проектах.

Не разрешаются произвольные загрузчики, package exports/tsconfig paths,
сторонние API, полные типы/CFG и все мутации. Тексты выбранных файлов буферизуются
в пределах общих лимитов; граф имеет дополнительные бюджеты. Это расходует память.
Один CI-прогон занял примерно 0,19/1,77/2,80 с для наборов 48/30/64, без загрузки
грамматик. Пик tracemalloc — 901 706 / 3 060 352 / 2 690 807 байт; он не охватывает
всю нативную память парсеров и не является гарантией скорости или памяти.
