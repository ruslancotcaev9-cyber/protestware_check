## Вход и запуск

Сканер связывает bare imports/requires с исходниками пакетов, которые **уже
выбраны** в том же входном дереве. Он не устанавливает зависимости, не читает
дополнительные файлы при разрешении импорта и не выполняет JavaScript.
Обычный профиль source исключает node_modules; artifact включает его:

```bash
python protestware_check.py --path ../application --profile artifact \
  --dependencies off --ast-mode auto --format json --output ./package-report.json
```

Сохраняйте отчёт вне проверяемого каталога. Заранее подготовьте грамматики JS/TS.
Параметр dependencies управляет инвентаризацией, а не загрузкой JS-модулей.
Сканер не расширяет выбранное дерево до полного node_modules автоматически;
исключения, размер файла и общие бюджеты продолжают действовать.

## Разрешение пакетов

| Сценарий | Поведение |
|---|---|
| Ближайший выбранный node_modules/name | Поиск вверх от импортёра, включая scoped-пакеты; неполный ближайший пакет блокирует переход к более дальнему |
| package.json | Строгий JSON; name должен соответствовать каталогу, type учитывается; дубликаты входных путей блокируют связывание пакета |
| Entry | main или index.js; строковый exports вида ./file.js; единственный выбранный .js/.cjs/.mjs |
| Подпуть | Выбранный статический подпуть разрешается при отсутствии exports; без расширения — .js либо index.js, неоднозначность отклоняется |
| ESM/CommonJS | Статические import/re-export и require в пределах существующего графа; require для ESM не поддержан, .cjs имеет приоритет над type=module |
| Core API | Встроенные модули имеют приоритет; выбранный node_modules/path не заменяет Node path |
| Нет выбранного пакета | Связь остаётся неизвестной; имя пакета само по себе не задаёт API |
| Опасный или неподдержанный entry | Выход за пакет, URL, абсолютные/кодированные пути, условные/object/subpath exports дают диагностику |

Обычный выбранный пакет анализируется по его тексту тем же ограниченным графом,
что локальные модули. Одноимённая безопасная функция не получает native identity.
Это ограниченная модель стандартного загрузчика, а не полный Node resolver.
Замеченные записи в require.cache/require.extensions, в том числе через alias,
блокируют последующие связи пакетов. Произвольные загрузчики, hooks, изменения
окружения извне и все эффекты runtime cache не моделируются.

## Модель graceful-fs 4.2.11

У этой версии экспорт формируется клонированием native fs и последующими
изменениями. Для шести методов удаления проверены исходники фиксированной
ревизии [514861c](https://github.com/isaacs/node-graceful-fs/tree/514861c372899df14beb7aaecca4cdbb498d7d11):
clone.js копирует свойства, graceful-fs.js экспортирует копию, а polyfills.js
и legacy-streams.js не заменяют перечисленные методы. На этой проверке кода
ассистентом основана модель **graceful-fs-4.2.11-deletion-exports-v1**.
Независимый человеческий аудит модели не выполнен.

Модель активируется только при точном совпадении UTF-8 SHA-256 **всех пяти**
выбранных файлов и подходящих name/version/main. Любой пропуск, изменение текста,
метаданных или дублирование критического пути отклоняет модель с диагностикой.
Полный список хешей — в [js_package_models.py](../js_package_models.py),
исходные тексты/Git blob SHA — в
[фикстуре](../tests/corpus/js-package-models/graceful-fs-4.2.11.json),
лицензия — [ISC](../tests/corpus/licenses/isaacs-node-graceful-fs.txt).

| Файл | SHA-256 |
|---|---|
| graceful-fs.js | 7da35669b6b6b0e4aafee31674c033f2cebb0c8f9ae010f709dcc185d3f17786 |
| clone.js | 7258eca52e65d69845759503f9fdd66c252f40e5eafb76db5d481172e31ac9ed |
| polyfills.js | 66ea1687ed5edf39d67296d26edccc8da695d9a869303a78d0e580cd770aca27 |
| legacy-streams.js | 60a6a7ecf7c3e55a3ffaae13433b6cff388b7205bba6daf393c863f77a949e36 |
| package.json | 5747d4ba6b17165c6ecac30ab3a331715f41c7ad546e1f1574dab1bdcb116181 |

Поддержаны require('graceful-fs') и default ESM import; моделируются только
rm, rmSync, unlink, unlinkSync, rmdir, rmdirSync. CommonJS .default и именованные
ESM-экспорты не предполагаются. Другие методы остаются непрозрачными. Замеченная
перезапись метода снимает его идентичность для последующих вызовов, сохраняя
снимок уже разобранных вызовов.

Совпадение текста означает соответствие входа этой узкой модели. Оно **не
подтверждает подлинность npm-артефакта**, целостность реестра, безопасность всего
пакета или фактическое исполнение вызова. Все выбранные внутренние модули также
проходят общий анализ; их partial и предупреждения сохраняются. Поэтому вызов
в main.js может иметь подтверждённую моделью связь, а весь отчёт —
ast.complete=false. required может вернуть 2 из-за внутренних ограничений.

## Доказательства в отчёте

| Поле | Содержание |
|---|---|
| ast.modules.packages | Использованные выбранные package roots, entry и metadata |
| ast.modules.package_models | ID модели, repository/revision и хеши совпавших файлов |
| ast.modules.package_lookups | Число уникальных поисков package entry |
| finding.dataflow | Шаги package-entry/package-model и конечный native sink; ключевой шаг модели сохраняется при усечении трассы до 24 шагов |
| finding.binding_basis | source-hash-model у находок с моделью |
| finding.package_models | Краткая привязка использованных в трассе моделей |

Поля аддитивны: report schema остаётся 1. Новые модули входят в отпечаток правил;
известные находки baseline возвращаются на ревью при изменении контекста.

## Границы и проверка

Дополнительные бюджеты: 256 package.json и 2 000 000 UTF-8 байт метаданных;
2 048 уникальных поисков и 64 уровня предков. Действуют прежние пределы графа:
256 JS/TS-модулей, 10 МБ, лимиты узлов, контекстов и сводок. Исчерпание бюджета
явно сохраняет partial; выбор полного установленного дерева может его превысить.

Закреплённые lib/remove/index.js и lib/move/move-sync.js из fs-extra теперь
связываются через выбранный graceful-fs с node:fs.rm/rmSync. Это не покрытие
всего fs-extra: динамическая сборка его главного API и universalify/apply остаются
ограниченными. Восемь использованных файлов перенесены в регрессию с отдельным
происхождением каждого helper. Эти изменённые проектные входы не являются новой
независимой оценкой. Метки и модель ожидают независимого ревью.

Основание для ограничений resolver:
[Node CommonJS](https://nodejs.org/api/modules.html) и
[Node packages](https://nodejs.org/api/packages.html).
