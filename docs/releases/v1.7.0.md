# protestware-check 1.7.0 — unreleased

Состояние разработки на 17.11.2026.
[Пакеты JS](../JS_PACKAGE_ANALYSIS.md) · [Проверка](../VALIDATION_1_7_0.md) ·
[Changelog](../../CHANGELOG.md).

- Bare imports/requires связываются с выбранными исходниками node_modules:
  ближайший пакет, main/default index, простой строковый exports и scoped names.
  Бюджеты, неоднозначности, type и неподдержанные формы отражены в диагностике.
- Шесть экспортов удаления graceful-fs 4.2.11 моделируются после точного
  совпадения пяти исходных файлов. Перезапись метода и замеченная подмена
  require cache снимают соответствующие связи. Target-код не выполняется.
- JSON/SARIF сохраняют package entry, ID/ревизию модели и основание связи;
  внутренние partial пакета остаются видимыми. Это не проверка подлинности npm.
- Восемь использованных файлов fs-extra перенесены в проектную регрессию:
  38 перенесённых сценариев, 56 оставшихся внешних. Helper-файлы из других
  репозиториев имеют собственные revision/path/license/hash.
- Полные входы, журнал и заморозка 1.6.0 архивированы. Метки сохранены;
  новые внешние источники и независимое человеческое ревью не добавлялись.

Report остаётся schema 1, baseline — 2, Go/status — 1. Новые поля аддитивны;
модули пакетов входят в отпечаток правил, поэтому baseline требует повторного
ревью при изменении контекста. Для анализа уже имеющегося node_modules нужен
профиль artifact; source продолжает исключать зависимости. Новых флагов нет.

Модель разрешает только указанные экспорты точной версии. Другие версии,
условные exports, произвольные загрузчики и весь API fs-extra не покрыты.
Версия остаётся в разработке; тег и GitHub Release этим этапом не создаются.
