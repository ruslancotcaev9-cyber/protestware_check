# protestware-check 1.5.0 — unreleased

Состояние разработки на 12.11.2026. [Документация](../README.md) ·
[Межфайловой JS/TS-анализ](../JS_MODULE_ANALYSIS.md) · [Changelog](../../CHANGELOG.md).

- Ограниченный граф локальных JS/TS-модулей поверх выбранных текстов: статические
  импорты/переэкспорты, CommonJS, прямые обёртки и вызываемые callback-параметры.
- `FS_DELETE` и `AST_GEO_ACTION` получают межфайловые цепочки; JSON/SARIF сохраняют
  расположение связей и нативного вызова. `ast.modules` показывает бюджеты/полноту.
- Неоднозначные пути, циклы, неподдержанные мутации и исчерпанные бюджеты явно
  оставляют анализ частичным; required возвращает 2. Target-код не выполняется.
- Восемь использованных файлов rimraf и контекст перенесены в регрессию.
  Четыре прежних положительных примера обнаруживаются с локальными модулями;
  три рекурсивных сценария сохраняют partial. Это изменение входного контекста,
  а не повтор независимой оценки на прежних однофайловых входах.
- Внешний набор содержит 64 сохранённых примера; новых источников не добавлено.
  Метки предварительные, независимое человеческое ревью не выполнено.

JSON report остаётся schema 1, baseline — 2, Go/status — 1. Новые поля аддитивны.
Изменение правил и набора выбранных файлов возвращает известные находки baseline
на ревью. Публикация релиза выполняется отдельно по [checklist](../RELEASE_CHECKLIST.md).
