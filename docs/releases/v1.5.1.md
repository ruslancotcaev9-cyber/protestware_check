# protestware-check 1.5.1 — unreleased

Состояние разработки на 17.11.2026. [Изменения](../../CHANGELOG.md) ·
[Уточнение JS/TS-анализа](../JS_PARTIAL_ANALYSIS.md) · [Полная проверка](../VALIDATION_1_5_1.md).

- Рекурсивные сводки файловых операций вычисляются до стабилизации рабочей очереди.
  Сохраняются отдельные контексты аргументов, ограниченные трассы и бюджеты.
- Spread разрешается по читаемым свойствам и порядку записей. Неиспользуемый spread
  не делает весь модуль частичным; реальная неоднозначность чтения остаётся partial
  с исходным файлом и строкой.
- Поиск NETWORK_FLOOD обходит конечный граф именованных функций без рекурсивной
  остановки. Общий бюджет поиска по всем циклам файла остаётся обязательным.
- Входы, предварительные метки и режимы корпусов сохранены. В восьми проектных
  регрессиях rimraf прежние TP/TN сохраняются, число partial снижено с пяти до двух.
  Свежая независимая выборка на этом этапе не добавлялась.

В report schema 1 аддитивно добавлено ast.modules.summary_steps. Baseline остаётся
schema 2, Go/status — 1. Изменение правил возвращает известные находки baseline
на ревью. Фабрики/возвращаемые функции, сторонние пакеты и полная семантика JS/TS
этим исправлением не реализованы. Версия не опубликована как GitHub Release.

Полный CI: 464 теста без пропусков; регрессии 48/30 без FP/FN. Проектные partial
снижены с пяти до двух; внешняя выборка сохраняет два FN и восемь partial.
