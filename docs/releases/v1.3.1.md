# protestware-check 1.3.1 — unreleased

Исторический этап разработки; текущие изменения — [1.3.2](v1.3.2.md).

Версия кода в `main`; этот документ не создаёт тег или GitHub Release.
[Документация](../README.md) · [Изменения](../../CHANGELOG.md).

- Исправлены Go dot import и переименованные импорты `os.Remove`/`os.RemoveAll`
  с проверкой затенения имён. Канонический символ сохраняется в JSON/SARIF и
  используется в `AST_GEO_ACTION`. Для этой возможности нужен Go AST-парсер;
  fallback остаётся ограниченным текстовым анализом.
- Добавлены PostgreSQL TRUNCATE без TABLE и валидатор допустимых опций перед
  структурным разбором. Комментарии, строки и идентификаторы не становятся командами.
- 14 использованных внешних примеров переведены в строгую регрессию; новый набор
  содержит 24 примера из 7 проектов, включая 8 целых файлов. Источники закреплены
  ревизиями и хешами, лицензии сохранены, target-код не исполняется.

Проверка: 352 unit-теста без пропусков, регрессионные наборы без FP/FN; во внешнем
наборе TP=11, TN=12, FP=0, FN=1. Сохраняется пропуск `fs.promises.rm`.
[Подробности и границы вывода](../EVALUATION_1_3_1.md).

CLI и форматы baseline не менялись. Смена правил меняет контекст schema 2:
известные находки могут вернуться на ревью при `--only-new`. Автоматически
утверждать новый baseline не следует. Остальные возможности и миграция — в
[заметках 1.3.0](v1.3.0.md).
