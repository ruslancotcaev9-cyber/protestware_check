# protestware-check 1.4.0 — unreleased

Состояние разработки на 12.11.2026. [Документация](../README.md) ·
[Changelog](../../CHANGELOG.md) · [Проверки](../VALIDATION_1_4_0.md).

- Полный JSON-отчёт CLI получил `schema: 1`, независимый от версии кода сканера.
  Добавлены пять JSON Schema Draft 2020-12 для отчёта, baseline 2/исторического 1,
  Go build-info и GitLab status. SARIF/CycloneDX сохраняют прежние форматы.
- `scripts/validate_json.py` проверяет артефакты по локальным схемам, без сети
  и исполнения проверяемого кода. Полная валидация требует `requirements-contracts.txt`;
  сканер и GitLab gate по-прежнему работают на стандартной библиотеке.
- Строгое чтение отклоняет дубли ключей, NaN/Infinity и чрезмерную вложенность.
  GitLab gate дополнительно сверяет счётчики, риск и сохранённый код завершения.
- Сохранены реальные старые отчёт/baseline 1.3.2 и примеры Go/status для
  воспроизводимой проверки совместимости. Добавлены 27 тестов контрактов.

Контрактная проверка: 403 unit-теста без пропусков, Go export/import, advisory-регрессии,
история на секреты; наборы 48/22/24 без FP/FN и ошибок. Оценочные примеры сохранены
из предыдущей версии; правила обнаружения в этом этапе не менялись.

Дополнительно выполнена [внешняя оценка v4](../EVALUATION_V4_2026-11-12.md):
421 тест без пропусков; 72 внешних примера, 58 целых файлов, 15 проектов. Метки
предложены ассистентом и ожидают ревью. Зафиксированы 6 FN и 8 partial; детекторы
не менялись. Добавлены журнал/таблица меток и раздельные метрики когорт/AST.

Потребители JSON должны учитывать `schema`. Для старых отчётов 1.3.0–1.3.2 helper
требует `--allow-legacy-report`; GitLab gate распознаёт эти версии автоматически
с сохранением digest первоначальных байтов. Неизвестная схема или новый отчёт
без `schema` дают ошибку. Baseline остаётся schema 2, Go/status — schema 1.
Контекст правил baseline изменился, поэтому известные находки могут вернуться
на рассмотрение. [Порядок миграции и пределы проверки](../JSON_CONTRACTS.md).

Корректный JSON-контракт не доказывает безопасность кода или доверенность
производителя артефакта. Версия остаётся в разработке; публикация релиза
выполняется по [контрольному списку](../RELEASE_CHECKLIST.md).
