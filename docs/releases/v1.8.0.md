# protestware-check 1.8.0 — unreleased

Состояние разработки на 18.11.2026.
[C# API](../CSHARP_BINDING_ANALYSIS.md) · [Проверка](../VALIDATION_1_8_0.md) ·
[Changelog](../../CHANGELOG.md).

- Добавлена ограниченная привязка System.IO File/Directory и экземпляров
  FileInfo/DirectoryInfo по тексту выбранного C#-файла. Поля/параметры,
  конструкторы, aliases и области затенения учитываются без исполнения кода.
- JSON/SARIF сохраняют resolved_symbol, selected-file-type и route; C#
  AST_GEO_ACTION использует ту же связь. При полном C# AST текстовые правила
  удаления заменены разрешением типов; при partial остаётся явный fallback.
- Неизвестные получатели и отсутствующие implicit/global usings из других
  файлов отражаются в partial; required возвращает 2. Полная семантика C#,
  контекст сборки и все варианты .NET API не заявляются.
- Четыре изученных файла Cake перенесены в регрессию. Наборы: 48 собственных,
  42 перенесённых, 56 прежних внешних и 20 оставшихся v7. Исходные 24 файла v7,
  первый JSON и кандидатные метки сохранены. Новых внешних источников нет.

Версии форматов прежние: report=1, baseline=2, Go/status=1. Новых флагов CLI
нет. Модуль входит в контекст правил; baseline требует повторного ревью при
изменении контекста. Версия остаётся unreleased, без тега и GitHub Release.

Полный CI: 541 тест без пропусков; регрессии 48/42 без FP/FN и ошибок.
Частичность: 10 в регрессиях, 8 в прежних внешних 56, 2 в остатке v7.
Остаток v7: TP8/TN10/FP0/FN2/ошибки0; Go-пропуски сохраняются.
