# protestware-check 1.9.0 — unreleased

Разрешение Go `os.Root.Remove/RemoveAll` по наблюдаемым импортам и типам.
Ограниченный граф выбранных файлов одного package сохраняет маршруты
через поля, аннотированные возвраты и конкретные локальные обёртки.

Добавлены отрицательные проверки пользовательских Remove/RemoveAll, затенения,
памяти, границ каталогов/test/build-тегов и callback-фабрик; тесты бюджетов,
required и JSON/SARIF. Итоговые результаты см. в
[проверке версии](../VALIDATION_1_9_0.md).

Четыре изученных файла Go переносятся в регрессию с закреплённым контекстом.
Исходная оценка v7 сохранена. Новая независимая внешняя оценка не проводилась.
[Область и ограничения](../GO_ROOT_ANALYSIS.md).

Форматы отчёта schema 1, baseline 2, Go import/status 1 сохранены.
Изменение правил требует повторного ревью baseline. Результат статического
анализа не доказывает исполнение или вредоносность.
