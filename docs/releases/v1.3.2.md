# protestware-check 1.3.2 — unreleased

Состояние разработки на 11.11.2026. Документ описывает код 1.3.2 и не создаёт
тег или GitHub Release. [Документация](../README.md) · [Изменения](../../CHANGELOG.md).

- Исправлен пропуск `fs.promises.rm`. `FS_DELETE` разрешает Node fs/fs-promises
  импорты, псевдонимы и деструктуризацию с учётом затенения и некоторых изменений
  namespace. Поддержаны JS/TS-расширения, optional calls, статические свойства
  и экранированные имена. Для этого нужны заранее загруженные AST-грамматики.
- JSON/SARIF сохраняют `resolved_symbol` и `binding_certainty`; географическая
  корреляция использует те же вызовы. Узкий сигнал shell-удаления через
  импортированные `child_process.exec/execSync` сохранён.
- Все 8 использованных JS/TS-примеров внешней оценки перенесены в регрессию и
  заменены данными других исходных файлов; оставшиеся 16 примеров сохранены.
  Реальные upstream-импорты и их хеши записаны в provenance, лицензии сохранены.

Проверено: 376 unit-тестов без пропусков; наборы 48/22/24 примера без FP/FN и
ошибок разбора. Это малые наборы без независимого подтверждения меток; результат
не переносится на произвольные проекты. [Доказательства и ограничения](../EVALUATION_1_3_2.md).

CLI и baseline schema 2 не изменились. Изменение правил возвращает известные
находки на ревью при `--only-new`; новый baseline утверждается после рассмотрения.
При полном JS/TS AST текстовое `FS_DELETE` заменено импортным разрешением.
При `off`/недоступном или частичном AST остаётся ограниченный fallback;
`required` возвращает 2 при диагностированной неполноте. Динамические загрузчики,
межфайловые переэкспорты и полная семантика JS/TS остаются вне этой версии.
[Подробности](../TECHNICAL_REFERENCE.md#nodejs-и-typescript).
