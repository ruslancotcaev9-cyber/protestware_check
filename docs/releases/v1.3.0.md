## Возможности

- Baseline schema 2 связывает рассмотренные находки с выбранным кодом, правилами,
  версиями используемых парсеров, настройками, зависимостями и политикой. При
  изменении контекста прежние находки получают `updated` и снова участвуют в gate.
- Готовые Go JSON из доверенного CI можно импортировать с проверкой ревизии,
  набора и SHA-256 исходных входов. Учитываются использованные выбранные модули,
  замены, связи и отдельные производственные профили; сканер Go не вызывает.
- Внешняя оценка добавляет 12 атрибутированных фрагментов шести проектов с
  закреплёнными ревизиями и лицензиями, отдельно от 48 регрессионных примеров.

Версия также включает ранее внесённые профили `source`/`artifact`, явную
TOML-политику, исключения со сроком действия, GitLab report/gate, Python
`SENSITIVE_DATA_SEND`, `AST_GEO_ACTION` для Go/C#/JS/TS, ограниченную пагинацию
advisories и доверенный офлайн-снимок с TTL. [Полная история](../../CHANGELOG.md).

## Миграция

1. Пересмотрите исходный отчёт и создайте baseline schema 2 через
   `--write-baseline`. Schema 1 не допускается для `--only-new`; возврат кода 2
   требует пересмотра, а не автоматического утверждения старых рисков.
2. Используйте одинаковые `--project-id`, политику и параметры при формировании
   baseline и последующих проверках. Отпечатки находок остаются версии 1.
3. Для Go передавайте `--go-build-info` и точный `--source-revision` только с
   локальным `--path` и `--dependencies lock`. Несколько профилей требуют отдельных
   снимков; без импорта сохраняется консервативная неполнота Go-графа.
4. Обновите закреплённый коммит сканера в CI после проверки. Задание GitLab gate
   должно оставаться обязательным: успешное сохранение отчёта не означает код 0
   самого сканера.

[Подробная миграция и подготовка Go JSON](../BASELINE_AND_GO_IMPORT.md).

## Проверка и ограничения

Для проверенного кода от 11.11.2026 прошли 326 unit-тестов без пропусков, реальный
импорт Go 1.27.4, поведенческая регрессия и проверка истории Git на секреты.
Собственный корпус: TP=24/TN=24/FP=0/FN=0. Внешний набор:
TP=4/TN=6/FP=0/FN=2; пропущены Go dot import и `TRUNCATE` без `TABLE`.
[Ревизия, CI и границы вывода](../EVALUATION_2026-11-11.md).

Python 3.11+; для полного мультиязычного анализа нужны закреплённые зависимости
сканера и заранее подготовленные грамматики. Baseline использует консервативный
контекст проекта, а не доказательство эквивалентности поведения. Go-импорт не
поддерживает тестовые пакеты, vendor, overlay и локальные замены вне source-root;
JSON не является подписанной аттестацией, байты module cache не проверяются.

Результат остаётся статическим triage: политический текст, репутационный список
или advisory сами по себе не устанавливают вредоносность. Отрицательный результат
не гарантирует безопасность. [Область анализа](../TECHNICAL_REFERENCE.md).
