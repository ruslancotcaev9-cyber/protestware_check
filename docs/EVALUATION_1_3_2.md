## Изменение детектора

Исправлен прежний пропуск `fs.promises.rm`. Для JS/TS добавлено ограниченное
разрешение Node `fs`/`fs/promises`: ESM/CommonJS, деструктуризация, псевдонимы,
статические свойства, optional calls, TS-обёртки и Unicode-экранирование имён.
Учитываются затенение, type-only imports, переприсваивание и некоторые прямые
изменения свойств. Одноимённый метод постороннего объекта не считается Node API.
Импортированные `child_process.exec/execSync` сохраняют узкий сигнал удаления
по распознанному статическому префиксу команды. Целевой код не исполняется.

`resolved_symbol` и `binding_certainty` сохраняются в JSON/SARIF. Известные вызовы
используются также в `AST_GEO_ACTION`. При неполном AST `auto` сохраняет fallback,
`required` возвращает 2. Семантика одного файла и ограничения обхода описаны в
[техническом справочнике](TECHNICAL_REFERENCE.md#nodejs-и-typescript).

## Границы вывода

Нулевая ошибка относится только к этим примерам. Фрагменты одного исходного
файла коррелируют; метки не прошли независимого человеческого подтверждения.
Положительная метка означает операцию, а не malware/protestware.

Не реализованы полные CFG/типы, произвольные межфайловые переэкспорты и загрузчики,
все изменения namespace и последствия других вызовов. CommonJS-инициализация
после рассматриваемого тела функции может быть неизвестна. Go-алиасы значений
функций и динамический SQL также остаются ограничениями. `ast.complete` сообщает
о диагностированной неполноте, но не обещает полную семантику языка.
Исторический FN сохранён в [оценке 1.3.1](EVALUATION_1_3_1.md); исправленный
пример теперь регрессионный. [Открытые задачи](ROADMAP.md).
