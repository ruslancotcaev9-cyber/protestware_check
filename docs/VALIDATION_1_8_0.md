## Неполнота и изменение поведения

В перенесённых регрессиях остаются 10 partial JS/TS-проектов. В остатке v7
сохраняются два partial TypeScript/Python из-за рекурсивного taint, оба TP.
В прежних 56 partial стало 8 вместо 6. Два дополнительных случая:
aspnetcore-whole-v4-2 и aspnetcore-whole-v4-3 используют Directory.Delete,
но using System.IO приходит из контекста сборки и не наблюдается в файле.
Теперь это явный C# unresolved receiver; auto сохраняет language-pattern
fallback, а не подтверждённую связь. Сами TP/TN не изменились.

Required на входе с таким неизвестным C# контекстом может вернуть 2, где
прежде применялся шаблон. Находки partial/fallback нельзя считать доказанной
native identity. Метод Delete чужого наблюдаемого типа при полном проходе
не получает файловое правило. FileSystemInfo и другие API, внешний build
контекст, другие экземпляры/getters, динамический dispatch и полные области
компилятора остаются ограничениями модели.

Новый binder ограничивает каждый из двух проходов 120 000 узлами и глубиной
120, выражения — глубиной 40, поиск контекста — 120 000 шагами. Generic-параметры
и namespace файла индексируются один раз. Выход за бюджет сохраняет partial
и уже обнаруженные вызовы. Никакие target-команды и дополнительные чтения
не используются. Типовая связь означает потенциальную операцию, не исполнение
пути и не признание пакета malware/protestware.
