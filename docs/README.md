## Интеграция

| Материал | Применение |
|---|---|
| [GitHub Code Scanning](../examples/github-code-scanning.yml) | Отдельный checkout проверяемого проекта и закреплённого сканера; SARIF |
| [GitLab CI/CD](../examples/gitlab-ci.yml) | Отчёт и обязательный gate с проверкой сохранённого результата |
| [Политика TOML](../examples/policy.toml) | Пример настроек и исключений с ответственным, основанием и сроком |
| [Экспорт Go](../scripts/prepare_go_build_info.py) | Нормализация заранее подготовленных JSON без вызовов Go; справка через `--help` |

Оба CI-примера закрепляют проверенный код сканера
`4451610330729f18dee0f9dc037c28945395f604`. Это существующий коммит, а не тег релиза.
Обновляйте его после проверки новой версии. Настройки, baseline и артефакты
производителя Go должны поступать из доверенной конфигурации CI.
