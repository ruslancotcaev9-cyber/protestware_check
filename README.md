# protestware-check

**Static source-code and software-supply-chain triage tool** / **Статический анализатор признаков protestware и рисков цепочки поставки ПО**.

`protestware-check` (v0.8.0) анализирует локальные каталоги и GitHub-репозитории **без выполнения проверяемого кода**. Находки предназначены для расследования специалистом по ИБ: **политические высказывания, географические ограничения и присутствие в сторонних списках сами по себе не доказывают вредоносность**.

> **Статус публикации:** репозиторий сейчас приватный. Документация подготовлена для будущей публикации; перед переводом в public выполните [контрольный список](docs/USER_GUIDE.md#перед-публичным-релизом).

## Возможности

| Область | Что проверяется |
| --- | --- |
| Protestware | Проверки страны/геолокации рядом с сетевыми и файловыми действиями; ограниченное отслеживание условий и вызовов |
| Сетевые вызовы | Неожиданные внешние URL, динамические адреса, некоторые сценарии массированных запросов (`NETWORK_FLOOD`) |
| Файловые операции и исполнение | Удаление, запись, запуск процессов, динамическое исполнение и API геолокации |
| Обфускация | Кодирование и характерные сочетания техник JS/TS (`OBFUSCATED_JS`) |
| AST / taint | Python; Tree-sitter для Go, C#, JS/TS, C/C++, SQL, HTML, CSS, SCSS, Less; ограниченный структурный разбор `.sass` |
| Зависимости | Lock-файлы npm, Python, Cargo, Composer, Go, NuGet; при необходимости — метаданные официальных реестров |
| Внешние источники | Опциональная сверка с `toxic-repos/toxic-repos` и `toxic-repos/black-mark` (контекст, **не вердикт**) |
| Отчётность | Текст, JSON, SARIF 2.1.0, CycloneDX JSON 1.6 |

**Область применимости:** синтаксический разбор не означает полноценный CFG/SSA. Межфункциональный анализ ограничен одним файлом; не охватывает все перегрузки, макросы, динамические вызовы, контекст сборки и пути через сторонние компоненты. Для C/C++ применяется ограниченный внут­рифайловый граф вызовов. Отрицательный результат — **не гарантия безопасности**.

## Быстрый старт

Требования: **Python 3.11+**, Git (для клонирования самого сканера) и интернет только для опциональных удалённых функций.

```bash
git clone https://github.com/ruslancotcaev9-cyber/protestware_check.git
cd protestware_check
python3 -m venv .venv
source .venv/bin/activate          # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements-ast.txt -r requirements-resolver.txt
python -c 'from tree_sitter_language_pack import download; download(["go","csharp","javascript","typescript","tsx","sql","html","css","scss","less","c","cpp"])'
```

Без установки необязательных пакетов доступны базовые эвристики; режим AST `required` требует загрузки соответствующих грамматик.

```bash
# Локальная проверка, без внешних списков; только зафиксированные зависимости
python protestware_check.py --path ../my-project --ast-mode auto \
  --dependencies lock --format json --output findings.json

# Проверка конкретного дерева GitHub; только чтение через API
python protestware_check.py --repo fmtlib/fmt --ref YOUR_COMMIT_SHA \
  --ast-mode auto --watchlists live --format sarif --output findings.sarif

# SBOM
python protestware_check.py --path ../my-project --dependencies lock \
  --format cyclonedx --output sbom.cdx.json
```

**Коды выхода:** `0` — завершено ниже порога, `1` — достигнут `--fail-on`, `2` — ошибка или неполный анализ при `--dependency-strict`. По умолчанию `--fail-on high`, `--watchlists off`, `--dependencies lock`, `--ast-mode auto`. Степень полноты AST и зависимостей смотрите в отчёте — не по одному коду выхода.

## Работа с находками

Сначала разберите `high` по файлу и строке, затем проверьте путь данных, достижимость, назначение компонента и влияние на пользователей. Отдельно оценивайте внешние списки и политический текст: эти индикаторы **не должны быть единственным основанием для признания пакета вредоносным**.

При анализе недоверенного кода запрещается запускать его сборочные скрипты и зависимости вне изолированной среды. Сам сканер не выполняет проверяемый код, но может делать HTTPS-запросы к GitHub и официальным реестрам, если эти режимы выбраны. JSON/SARIF-отчёты могут содержать фрагменты приватных исходников — контролируйте доступ.
